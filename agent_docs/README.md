# Agent Reference Documentation

This directory holds stable, implementation-backed references that are too detailed for `AGENTS.md`. Future work and unimplemented proposals belong in Beads, not here.

Current references:

- `agent-runtime.md` documents the live agent's input modes, durable state, ordering, delivery acknowledgement, configuration, and recovery contracts.
- `peer-observer-wire.md` records the pinned protobuf import closure, live NATS payload semantics, hash handling, and raw archive framing.
